# Backend (FastAPI)

## 概要
Python 3.12+ と FastAPI を用いて構築されたバックエンド API サーバーです。
フロントエンドから送信された Cognito の JWT トークンを検証し、認証済みユーザーのデータを操作する API を提供します。
パッケージ管理には `uv` を使用し、依存関係は `pyproject.toml` で管理（バージョン固定）されています。
