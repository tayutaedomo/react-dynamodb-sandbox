# Frontend (React)

## 概要
Vite と React (v16) を用いて構築されたフロントエンド・アプリケーションです。
AWS Amplify SDK を利用して Cognito へのログイン・認証を行い、取得した JWT トークンを用いてバックエンド API (FastAPI) と通信します。

## 開発サーバーの起動手順

1. `.env` ファイルに AWS Cognito や API Gateway のエンドポイント等の環境変数が設定されていることを確認します。
2. 依存パッケージをインストールします。
   ```bash
   npm install
   ```
3. 開発サーバーを起動します。
   ```bash
   npm run dev
   ```
4. ブラウザで `http://localhost:5173` にアクセスします。

## テストの実行

本プロジェクトでは、2種類のテストを用意しています。

### 1. 単体テスト (Vitest)
コンポーネントのルーティングや、UI の描画ロジックを API のモックを用いて高速に検証します。
```bash
npm test
```

### 2. E2E テスト (Playwright)
実際のブラウザ（Chromium 等）を自動操作し、API モックを使わずに本物のバックエンドインフラ（AWS）と通信して動作検証を行います。

#### E2E テストの前提条件
E2E テストは本物のインフラと通信するため、以下の条件を満たしている必要があります。
*   ローカルの開発サーバー (`npm run dev`) が `http://localhost:5173` で起動していること。
*   バックエンドインフラ (Cognito, API Gateway, DynamoDB 等) が AWS 上にデプロイされており、正常に通信できる状態であること。
*   テスト対象のユーザー（例: `testuser2` とパスワード `Password123!`）が Cognito User Pool に登録済であること。

#### 実行手順
別のターミナルを開き、以下のコマンドを実行します。
```bash
npm run test:e2e
```

#### テスト実行結果とトレース（画面キャプチャ）の確認
テスト終了後、以下のコマンドを実行するとレポート画面が開きます。
```bash
npx playwright show-report
```
このレポート画面では、**テストのアクション（クリックや入力）ごとに、その瞬間の画面キャプチャ（DOMスナップショット）やネットワークの通信履歴を確認することができます。** テストが成功した場合でも失敗した場合でも、UI がどのように変化したかを事後確認するのに非常に便利です。
